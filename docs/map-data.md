# Map data

Global silhouette: Natural Earth 1:110m land, converted once to equirectangular SVG. [Terms](https://www.naturalearthdata.com/about/terms-of-use/) place the data in the public domain. The UI credits Natural Earth.

[Source repository](https://github.com/nvkelso/natural-earth-vector): `geojson/ne_110m_land.geojson`. `scripts/map.mjs` reproduces the committed asset, so gameplay needs no map service. Regional terrain is deterministic fiction, never real property boundaries or house locations. Political borders are not rendered.
